# F 误读预警
| 误读位置 | 预警内容 |
| :--- | :--- |
| 第 2–3 页 | 容易被写成什么：所有资料外泄都要尽快通知客户。<br>原文实际是什么：“as soon as practicable”用于严重私隐事故；一般情况是“as appropriate”，决定不通知的要说明理由。 |
| 第 3 页 | 容易被写成什么：《私隐条例》写明银行不必向私隐专员报告。<br>原文实际是什么：“no statutory requirement”是这份通函的说法，引用时出处写 H9。 |
| 第 3 页 | 容易被写成什么：通函引的就是 H10。<br>原文实际是什么：通函引的是私隐专员当时的“Guidance Note on Data Breach Handling and the Giving of Breach Notifications”，H10 是 2023 年 6 月的另一个版本。 |

# G 本文件不回答什么
1. 不涉及客户资料的网络事故怎么通报（见 H3、H4）。
2. 通报的小时时限。
3. 赎金能不能付。
